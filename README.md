# WordPress Technical SEO Toolkit

Production-focused technical SEO patterns for WordPress covering indexing controls, canonicals, metadata, structured data, redirects, taxonomy strategy, and image SEO.

This repository is designed as a maintainable engineering reference rather than a collection of aggressive SEO snippets.

## Principles

- use WordPress APIs before raw markup or database writes
- keep behavior opt-in and safe by default
- avoid duplicate metadata when an SEO plugin already owns the page head
- distinguish crawl control, indexing control, canonicalization, and redirects
- validate structured data instead of assuming eligibility
- document taxonomy and parameter risks before changing indexation
- test redirects, canonicals, robots directives, and XML sitemap behavior together
