# Contributing

Contributions should be conservative, testable, and based on documented WordPress/search-engine behavior.

Before opening a pull request:

1. branch from `main`
2. run `composer install`
3. run `composer lint`
4. document indexation/canonical/redirect implications
5. note compatibility with major SEO plugins
6. explain how the rendered output was tested

Do not contribute tactics that depend on hidden text, fabricated structured data, cloaking, misleading redirects, or other deceptive behavior.
