# XML Sitemaps

An XML sitemap is a discovery aid, not a command to index every listed URL.

## Prefer sitemap consistency

URLs in a sitemap should generally be:

- canonical
- indexable
- successful HTTP responses
- intended for search discovery

Avoid routinely listing redirected, noindexed, duplicate, or error URLs.

## WordPress

WordPress provides core XML sitemap functionality, while SEO plugins may replace or extend it.

Do not run multiple competing sitemap systems without understanding which one is authoritative.

## After major URL changes

Check:

- sitemap URLs
- redirects
- canonicals
- robots directives
- internal links
- Search Console sitemap processing
