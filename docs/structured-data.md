# Structured Data

Structured data should describe visible, truthful page content.

## Principles

- use the most specific appropriate schema type
- do not invent reviews, ratings, prices, availability, or business facts
- keep structured data consistent with visible content
- use valid absolute URLs
- avoid duplicate/conflicting graphs from multiple plugins

## Validation

After implementation:

1. validate JSON syntax
2. test the rendered page, not only source templates
3. use Google's supported rich-result testing where applicable
4. review Search Console enhancement reports when available
5. re-test after theme/plugin changes

Valid schema does not guarantee a rich result. Eligibility and display are controlled by the search engine.
