# Technical SEO Testing Checklist

## Indexation

- [ ] intended pages return index/follow behavior
- [ ] noindex pages remain crawlable when needed for directive discovery
- [ ] internal search results are handled intentionally
- [ ] author/tag archives match the site's strategy

## Canonicals

- [ ] one canonical tag
- [ ] canonical is absolute
- [ ] canonical returns a successful response
- [ ] canonical target is indexable
- [ ] sitemap and internal links prefer the canonical URL

## Redirects

- [ ] expected status code
- [ ] no loop
- [ ] no unnecessary chain
- [ ] destination is relevant
- [ ] internal links updated

## Metadata

- [ ] one title owner
- [ ] one meta description owner
- [ ] no duplicate canonical output
- [ ] no duplicate robots output

## Structured data

- [ ] valid JSON-LD
- [ ] visible content supports the claims
- [ ] URLs resolve
- [ ] no fake ratings/reviews/business data

## Images

- [ ] meaningful alt text where needed
- [ ] decorative images use empty alt where appropriate
- [ ] primary images are crawlable
- [ ] dimensions/aspect ratio reduce layout shift

## Sitemaps

- [ ] only intended canonical/indexable URLs
- [ ] successful responses
- [ ] no redirected/noindexed URLs in normal sitemap set
