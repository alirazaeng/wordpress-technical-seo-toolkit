# Taxonomy Strategy

WordPress can generate many archives: categories, tags, product categories, product tags, brands, authors, dates, and custom taxonomies.

The correct strategy is not "index everything" or "noindex everything."

## Keep an archive indexable when it has

- a clear search intent
- unique and useful content
- meaningful inventory or posts
- internal links
- stable pagination
- a distinct role in the site's information architecture

## Consider noindex when an archive is

- redundant
- extremely thin
- automatically generated with no search purpose
- duplicative of a stronger category/brand page
- a search-results page or other low-value internal result set

## WooCommerce

Commercial taxonomies such as product categories and brands can be high-value landing pages. Product tags often need more scrutiny because stores frequently create many overlapping or thin archives.

Evaluate each taxonomy type deliberately instead of applying one global rule.
