# Image SEO

Image SEO starts with accessibility, relevance, and crawlable media—not keyword stuffing.

## Alt text

Alt text should communicate the image's purpose in context.

Good alt text is:

- useful to users who cannot see the image
- concise
- contextual
- not a list of keywords
- empty when an image is purely decorative

## File names

Readable file names can improve maintainability and provide context, but renaming production media solely for SEO can create broken references if migration is not handled correctly.

## Dimensions and layout stability

Serve appropriately sized images and reserve dimensions/aspect ratio to reduce layout shift.

## Product images

For commerce:

- use accurate product imagery
- keep product names/variants understandable
- avoid misleading alt text
- ensure primary images are crawlable
- preserve image URLs during migrations where practical

## Structured data

Image URLs used in structured data should resolve correctly and correspond to the represented entity.
